# Mini App

მცირე ზომის ვებ-აპლიკაცია (Mini App), რომელიც შექმნილია სწრაფი და მოხერხებული მოხმარებისთვის.

## 🚀 ფუნქციონალი (Features)

* **მარტივი ინტერფეისი:** მოსახერხებელი და ინტუიციური დიზაინი.
* **სწრაფი მუშაობა:** მინიმალისტური კოდი მაქსიმალური წარმადობისთვის.
* **კროს-პლატფორმულობა:** მუშაობს ნებისმიერ თანამედროვე ბრაუზერში.

## 🛠 ტექნოლოგიები (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** (თუ იყენებთ Python/Django, Node.js ან სხვა Framework-ს, ჩაწერეთ აქ)

## 📦 პროექტის გაშვება ინსტრუქცია

1. **რეპოზიტორიის კლონირება:**
   ```bash
   git clone [https://github.com/lxka806/Mini-App.git](https://github.com/lxka806/Mini-App.git)
   cd Mini-App

```

2. **პროექტის გახსნა:**
* თუ აპლიკაცია მხოლოდ ფრონტენდია: უბრალოდ გახსენით `index.html` ფაილი ბრაუზერში.
* თუ იყენებთ Node.js-ს:
```bash
npm install
npm start

```


* თუ იყენებთ Python-ს:
```bash
python main.py

```
